    加载本地网页，开始可视化编辑

    点击「选择文件夹」并选中包含网页的目录（推荐，可自动加载同目录的图片 / CSS / JS），
    或点击「打开HTML」加载单个文件，也可以把文件夹或 HTML 文件直接拖拽到本窗口。

    文字：开启「编辑」后，点击文字直接修改，像 Word 一样
    拖拽：开启「拖拽」后，按住元素直接移动；按住 Shift 可锁定横向 / 竖向
    样式：选中元素后，用顶栏「字体 / 背景 / 边框」选项卡调整，顶栏不会遮挡页面
    格式刷：复制选中元素的样式，点击目标元素即可应用
    结构：「父级 / 子级」逐层查看并切换选中元素
    撤销：所有修改（含重置、绝对定位转换）都可撤销 / 重做
    保证：除文字、颜色、字体、位置外，页面结构、布局、CSS、图片、动画保持原样

    选择要编辑的页面

      使用帮助

      一、加载页面

      「选择文件夹」选中包含网页的目录后，从列表中选择入口 HTML。同目录下的图片、CSS、JS、字体等相对资源会被自动加载。也可以直接拖拽文件夹 / 多个文件到窗口。

      二、编辑（顶栏「编辑」开关）

      • 改文字：直接点击页面上的文字，即可像 Word 一样输入修改（自动全选，输入即替换）；Esc 放弃修改并保持选中。编辑模式下超链接、按钮等交互元素不会被触发。
      • 选中元素：点击元素出现橙色高亮；再次点击容器可逐级切换到父元素，或用顶栏「父级」按钮。
      • 样式：选中元素后，用顶栏「字体」（文字色、字号、字重 100–950 可自定义、行高、字距、字体、斜体）、「背景」（背景色、透明度、阴影）、「边框」（边框色、宽度、样式、圆角）调整。选项卡打开时显示该元素自身的行内值，未设置的项留空；均为行内样式、可单项清除。
      • 格式刷：点击格式刷图标吸取选中元素的样式，再点击目标元素即可应用（一条修改记录，可撤销，Esc 取消）。
      • 位置：顶栏 X/Y 输入精确坐标后点「应用坐标」；或开启「拖拽」后按住元素直接拖动（按住 Shift 锁定横向 / 竖向）。
      • 结构：「父级」上溯父元素；「子级」列出全部子元素，点击即可选中。
      • 「位置」可选平移（不影响布局）或绝对定位（元素脱离文档流，切换与首次拖动都有提示、且可撤销）。
      • 「重置」清除选中元素全部修改（可撤销）；「撤销 / 重做」管理全部修改历史。

      三、导出

      「导出」下载修改后的完整页面（相对资源引用自动还原）；「保存」写回原目录（需 Chrome/Edge）；「记录」导出 JSON 补丁便于审计。

      四、已知限制

      • JS 动态渲染的页面（SPA）重渲染后会丢失编辑，静态页面不受影响。
      • 页面自身 JS 中的相对路径 fetch/XHR 在编辑环境不可用（img/css/js 标签引用不受影响）。
      • 绝对外链资源（如 CDN 图片）需要联网。
      • 平移属于视觉偏移、不重新排版（这正是"布局保持原样"的保证）。
