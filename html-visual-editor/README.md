# 🎨 HTML 可视化编辑器

加载本地 HTML 页面后，在浏览器里直接可视化地修改**文字、颜色、字体样式、位置**。除此之外，页面的**结构、布局、CSS、图片、动画全部保持原样**。

## 启动

**无需后端**：在 Chrome / Edge 中直接双击打开 `index.html` 即可使用全部功能（页面通过 `document.write` 写入同源 iframe、资源用 Blob URL 加载，不依赖任何服务器）。

需要更稳妥的体验（Firefox / Safari、避免个别浏览器对 `file://` 的额外限制）时：

```bash
node serve.js          # 默认 http://127.0.0.1:8123（自动打开浏览器）
node serve.js 9000     # 自定义端口
node serve.js --no-open
```

## 加载页面

- **📁 选择文件夹**（推荐）：选中包含网页的目录，从列表选择入口 HTML。同目录下的图片、CSS、JS、字体等相对资源会自动加载。要求 Chrome / Edge。
- **📄 打开HTML文件**：加载单个 HTML（不含同目录资源）。
- **拖拽**：把文件夹或多个文件直接拖进窗口。

## 编辑（顶栏 Word 式功能区）

顶栏按功能分组：**加载 ｜ 模式 ｜ 元素编辑 ｜ 历史 ｜ 导出**。所有编辑控件都在顶栏，**不会遮挡页面元素**。

| 操作 | 方法 |
| --- | --- |
| 修改文字 | 开启「✏️ 编辑」后**直接点击页面文字**即可输入（自动全选，输入即替换），像 Word 一样；Esc 放弃修改并保持选中；顶栏「文字」可再次编辑 |
| 编辑模式静默 | 编辑模式下**超链接不跳转、按钮不运行**（含中键点击、右键菜单），交互元素点击只选中、不会误触发 |
| 选中元素 | 点击元素（橙色高亮，顶栏显示元素标签）；点击容器再次点击同一处逐级上溯，或点顶栏「父级」 |
| 字体与文字色 | 顶栏「字体」：文字色、字号、**字重（1–1000 自定义数值）**、行高（倍率或单位）、字距、**字体（长输入框，可自定义，内置 40+ 常见中英文字体）**、斜体；选项卡打开时显示**该元素自身的行内值**，未设置的项留空 |
| 背景 | 顶栏「背景」：背景色、透明度、阴影 |
| 边框 | 顶栏「边框」：边框色、宽度、样式（实线/虚线/点线/双线）、圆角 |
| 格式刷 | 顶栏画笔图标：吸取选中元素的样式，再点击目标元素一次性应用（可撤销，Esc 取消） |
| 子级元素 | 「子级」列出选中元素的全部子元素，点击即可选中 |
| 精确位置 | 顶栏 X / Y 输入坐标后点「应用坐标」（回车亦可） |
| 拖拽位置 | 开启「🖐 拖拽」后**按住元素直接拖动**，全程无确认框；**按住 Shift 锁定横向 / 竖向**；指针在已选中元素内部时拖动的是整个选中元素（悬停高亮会预告拖动目标） |
| 恢复 | 「重置」清除某元素全部修改；「撤销 / 重做」管理全部历史 |
| 退出编辑模式 | 关闭「✏️ 编辑」开关，页面恢复可正常浏览、点击链接 |

### 两种位置方式（顶栏下拉）

- **平移（默认）**：使用 CSS `translate` 属性视觉移动。不改变文档流与布局，与页面自身的 transform 动画可叠加（元素原有动画不受影响）。原位置会保留占位。
- **绝对定位**：元素脱离文档流真正重新定位，周围元素会重排。切换时仅 toast 提示；拖动或应用坐标时自动原位转换（视觉不变），转换本身可撤销。

所有操作均无确认弹窗——一切修改都可撤销，做错了撤销即可。

## 导出

- **⬇ 导出HTML**：下载修改后的完整页面，相对资源引用自动还原为原路径。
- **💾 保存回原文件**：文件夹模式下直接写回原文件（Chrome/Edge）；其他环境弹出保存对话框或退化为下载。
- **🧾 修改记录**：导出 JSON 补丁（元素路径、修改前后值），便于审计。

## 实现原理（为什么能"保持原样"）

所有编辑只写入两种东西：

1. **文字节点的文本内容**——且提交时校验只允许纯文本与 `<br>`，一旦检测到元素插入立即回滚，从机制上杜绝结构破坏；含子元素的容器不允许整体编辑，只能点击内部的具体文字元素。
2. **元素的行内 `style` 属性**（颜色、字体样式、`translate` / 绝对定位）——行内样式只覆盖该元素自身，不触碰任何 `<style>` 块、外链 CSS 规则、DOM 结构、图片与动画定义。

导出时清理所有编辑器注入物（运行时脚本、高亮层、提示气泡、辅助标记与拖拽光标类），导出的 HTML 与源文件逐节点 diff 仅包含上述编辑点。

## 已知限制

- JS 动态渲染型页面（SPA）在重渲染后会丢失编辑；静态页面不受影响。
- 页面自身 JS 中的相对路径 `fetch`/`XHR` 在编辑环境不可用（`<img>/<link>/<script>` 标签引用不受影响）。
- 绝对外链资源（CDN 图片等）需要联网。
- 平移是"视觉偏移"而非重新排版——这正是布局保持原样的保证；需要真实重排时切换绝对定位模式。
- 页面内嵌 iframe、`<base href>` 指向外部站点的页面按浏览器规则加载，编辑范围仅限顶层文档。
- 直接以 `file://` 双击打开时，`showDirectoryPicker` 等能力取决于浏览器策略，建议用 serve.js。

## 目录结构

```
html-visual-editor/
├── serve.js            # 零依赖静态服务器
├── index.html          # 编辑器外壳（Word 式顶栏功能区 / 舞台 / 帮助）
├── editor.css          # 外壳样式
├── editor.js           # 外壳控制器：加载、资源重写、撤销栈、导出、顶栏控件
├── runtime.js          # 注入目标页面的编辑运行时（高亮 / 文字 / 拖拽 / 样式，自渲染 CSS）
├── test/
│   ├── fixture-site/   # 测试用示例站点（文字/颜色/图片/动画/布局）
│   └── compare-png.js  # 零依赖 PNG 像素对比工具
└── README.md
```

## 已验证（Playwright 自动化）

- 文件夹/文件加载与相对资源（CSS/JS/图片）解析（file:// 免后端与 http:// 两种模式）
- 点击文字直接编辑、结构保护（元素插入自动回滚）、Esc 放弃保持选中
- **编辑模式静默**：链接不跳转、按钮/JS 事件不运行、中键点击不打开新页、右键菜单被抑制
- 字体（文字色/字号/自定义字重 1–1000/行高/字距/字体/斜体）、背景（背景色/透明度/阴影）、边框（颜色/宽度/样式/圆角）选项卡；打开时预填元素自身行内值、未设置留空
- **格式刷**：吸取样式 → 点击目标元素应用（不误触文字编辑）、Esc 取消、可撤销
- 坐标精确应用、父级 / 子级（列表选中）、容器双击上溯
- 拖拽模式：按住元素直接拖动（零确认框）、Shift 锁定横向/竖向、坐标实时联动
- 绝对定位：切换与首次拖动均无弹窗、原位转换（宽高/margin 固化）、整步撤销恢复文档流
- 撤销/重做链、元素重置（覆盖全部样式项）
- 遮挡检查：iframe 内无任何面板/工具栏类 UI，编辑中元素可被直接命中
- 导出 HTML 与原文件结构级 diff：**除编辑点外零差异**（结构/属性/CSS/图片/动画全一致，无任何编辑器残留）
- 未编辑区域（页头、页脚）编辑前后截图像素级一致（0.0000% 差异）
